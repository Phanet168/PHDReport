# Mobile Flutter Project

## Setup
1. Ensure you have Flutter installed on your machine. Follow the official Flutter installation guide.
2. Clone this repository to your local machine.
3. Navigate into the `Mobile` directory.
4. Run `flutter pub get` to install dependencies.

## Running the App
Run `flutter run` to start the application on your connected device or emulator.
